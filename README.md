# 📊 Sales Dashboard - Power BI

## 🔍 Overview
An interactive sales dashboard built in Power BI to track and analyze 
online sales data across multiple regions of India.

## ✨ Features
- 📈 **Time Series Forecasting** – Predicts next 15 days sales using historical data
- 🔎 **Drill-Down Analysis** – Granular exploration by region, category & sub-category
- 🎛️ **Dynamic Filters & Slicers** – Interactive parameters for custom data views
- 🗺️ **Regional Insights** – State-wise and city-wise sales performance
- 💰 **KPI Tracking** – Revenue, profit, quantity and order metrics at a glance

## 🛠️ Tech Stack
- **Tool:** Microsoft Power BI Desktop
- **Data:** SuperStore Sales Dataset (CSV)
- **Files:** Orders.csv, Details.csv

## 📁 Files in this Repo
| File | Description |
